NavyHUD v2.9  使い方
===================
1. build.bat をダブルクリック
   (Python が無ければ winget で自動インストール → もう一度 build.bat)
   (FPS測定用の PresentMon 最新版も自動でダウンロードして exe に同梱します)
2. 数分後、同じフォルダに NavyHUD.exe ができます。
3. NavyHUD.exe は起動時に「管理者として実行」の確認が出ます。
   これはFPS測定 (Windowsのイベントトレース) に必要です。「はい」を選んでください。

更新・動作確認のしかた (毎回ビルドし直さなくて大丈夫です)
- 新しい navyhud.py を受け取ったら、今の NavyHUD フォルダの navyhud.py に「上書き」するだけでOKです。
  フォルダやアプリを消す必要はありません。設定 (%APPDATA%\\NavyHUD) もそのまま残ります。
- すぐ試す: run.bat をダブルクリック (ビルドなしで数秒で起動。初回だけ環境作りに数分かかります)。
- exe にしたいとき: build.bat (既存の .venv と PresentMon を再利用するので、2回目以降は短めです)。
- run.bat 起動中は黒い画面が出ます。エラーが出たときはその文面がそこに表示されます。

便利ショートカット: マイクのミュート (v2.9)
- 「システム > 便利ショートカット」で ON/OFF (初期値 OFF)。ONにすると、どのアプリが前面でも
  Ctrl + Shift + M を押すたびに、マイクのミュート / ミュート解除が切り替わります。
- 対象は Windows の「既定の録音デバイス」です。Discord などで既定とは別のマイクを選んでいる場合は、
  そのマイクはミュートされません (Windowsの設定 > サウンド > 入力 で既定のマイクを確認してください)。
- 切り替えるたびにWindows側の実際の状態を読んで反転するので、他の方法でミュートしても食い違いません。
- 同じ画面の「マイクの状態」で、今ミュート中かどうかを確認できます。
- Teams など、Ctrl+Shift+M を使う他のアプリがあると同時に反応します。その場合はOFFにしてください。

FPSの追加表示: 1% Low / 0.1% Low / 平均 (v2.9)
- FPSカードの詳細設定 > FPS測定 > 「追加の表示」で、1% Low / 0.1% Low / 平均FPS をそれぞれ表示ON/OFFできます (初期値 OFF)。
- FPSの下に同じ幅で並びます。文字の色・背景・枠・大きさなどはFPSの設定がそのまま共有されます
  (キーストロークの「右/左クリック」と同じ仕組み)。プリセットにも保存されます。
- 計算方法: 直近60秒のフレーム時間を使います。
    平均FPS  = フレーム数 ÷ 経過時間
    1% Low   = 遅かった方から1%のフレームの平均フレーム時間を FPS に直した値
    0.1% Low = 遅かった方から0.1%のフレームについて同様に計算
  フレーム数が足りないうちは「--」です (1% Low は100フレーム、0.1% Low は1000フレームほど必要。60FPSなら約17秒)。
- 0.25秒ごとに計算するので、更新間隔を短くしても負荷は増えません。

キーストロークの追加: ダッシュ / スプリント (v2.9)
- キーストロークカードの詳細設定で「ダッシュを表示」「スプリントを表示」をそれぞれ選べます (初期値 OFF)。
  ONにすると、スペースの下に「DASH」「SPRINT」の枠が出ます (両方ONなら1段に2つ並び、片方だけなら横いっぱい)。
- ゲームの中でダッシュ/スプリントしているかどうかは分かりません。割り当てたキーが「押されているか」だけを表示します。
- 初期の割り当ては ダッシュ = Shift、スプリント = Tab です。詳細設定の「キー割り当て」で変えられます。
- 文字の色・背景・枠・押したときの色などは、他のキーと共通の設定です。

詳細設定の画面 (v2.9)
- 詳細設定の右上にあった「表示 ON/OFF」のボタンを削除しました。表示のON/OFFは、表示設定の一覧のカードのボタンで切り替えます。

ゲームが最前面のときだけHUDを表示 (v2.8)
- 「システム > 表示するタイミング」でON/OFF (初期値ON)。対象のゲームがウィンドウの一番手前にあるときだけHUDを出し、
  ブラウザなど他のアプリに切り替えると隠れます。NavyHUDの設定画面が最前面のときは、設定しやすいよう常に表示します。
- 対象のゲームはプロセス名で指定します (初期値: Minecraft.Windows.exe, javaw.exe)。カンマで区切って追加できます。
- HUDが出ないとき: ゲームを前面にしてからNavyHUDの設定画面に戻り、「システム > 表示するタイミング」の
  「直前に最前面だったアプリ」がゲームの名前なら、「対象のゲームに追加」を押してください。
- PingはHUDが隠れている間も測り続けます (戻ったときにすぐ数字が出ます)。

詳細設定を開いている間 (v2.7)
- 詳細設定(プレビュー表示)を開いている間は、他のウィンドウをクリック/Alt+Tab しても、Windowsの警告音が鳴って
  設定画面に戻ります。「‹ 戻る」(または×)で解除されます。タスクトレイの操作だけは許可しています。
- 「システム > 起動」の「詳細設定中は他のウィンドウに切り替えさせない」をOFFにすると、この動作を止められます。

操作
- 設定画面: カードをクリックで詳細設定 / ボタン 青=表示・暗い色=非表示
  (設定画面の大きさは固定です。表示設定のカードは左から順に並び、3枚で次の段(二段目)へ折り返します)
  (背景・枠などをOFFにすると、その関連設定は非表示になります)
- HUD移動: Ctrl + 左クリックドラッグ (画面中央に固定のX線(横)/Y線(縦)が出て、HUDの中心が近づくと線に吸着。離すとカーソルに戻ります)
- 設定画面を×で閉じてもHUDは動き続けます。タスクトレイのアイコンから再表示/終了。
- 設定の保存先: %APPDATA%\NavyHUD\config.json (変更するたび自動保存)

FPSについて
- 仕組みは PC_Monitor と同じです: PresentMon(公式の最新版)を起動し、ゲームが出したフレームの間隔(msBetweenPresents/FrameTime)から
  「直近1秒のフレーム数」を計算します。パイプの受信が遅れても数字がぶれません。
- 測定対象は「最前面のウィンドウのゲーム」を自動判定。複数起動時は FPS詳細 > 測定 でプロセス名(javaw.exe など)を指定。
- マイクラ側の数字と1~2ずれる場合は、更新間隔を 1.0秒 のままにしてください。
  (マイクラのF3は1秒ごとに数字を更新するため、更新の瞬間の差で多少ずれます)

Ping (v2.4で追加 / v2.5で測定方法を強化)
- 表示設定の二段目の「Ping」カード。サーバー(ホスト)までの応答時間をmsで表示します。
- 詳細設定は他のHUDと同じ: 全体 / 文字(色・大きさ・字間など) / 背景(色・不透明度) / 枠(色・太さ・不透明度・外側へのぼかし) に加え、
  「Ping測定」タブで 表記(数字のみ / 32ms / PING:32ms)・更新間隔・測定先 を変えられます。
- 「測定先のアドレス」にはサーバーのIPアドレスかホスト名を入れます (初期値 1.1.1.1)。管理者権限は不要です。
  ポート番号は別の「ポート (任意)」欄に入れます。アドレス欄にポート番号「だけ」を入れても測れません。
  例) アドレス play.example.net / ポート 19132   (アドレス欄に play.example.net:19132 と続けて書いてもOK)
- 測り方 (自動で順番に試します。「状態」欄にどの方法で測れたか、駄目だった場合は試した方法が出ます):
  (全角文字・http://・末尾の/パス・「ホスト 19132」・日本語ドメインも読み取ります)
  ポートなし      : ping(ICMP) → 駄目なら TCP 443 → TCP 80 の接続時間で代用
  ホスト:ポート   : そのポートで測ります。19132/19133 (統合版の標準) は、サーバーにUDPで問い合わせた応答時間 (RakNet)。
                    それ以外のポートは TCP接続時間 → 駄目なら RakNet。 例) play.example.net:19132
- 「Ping測定」タブ上部のテンプレートボタン (v2.8): 押すとアドレスとポートが自動で入ります (統合版・ポート19132)。
    Hive      geo.hivebedrock.network   (地域ごとに自動で近いサーバーへ。固定したいときは sg.hivebedrock.network など)
    Zeqa      zeqa.net
    CubeCraft play.cubecraft.net        (mco.cubecraft.net でも可)
  今の測定先と同じテンプレートのボタンは青く光ります。ほかのサーバーは下の欄に直接入力してください。
- 表示がONのとき(または設定画面を開いている間)だけ測定します。測れないときは「--」を表示します。
- プリセットはPingの見た目も保存します。v2.3以前に保存したプリセットはPingの設定を含まないため、適用してもPingの見た目は変わりません。

プリセット
- 左の「プリセット」: HUDの見た目(色・文字・背景・枠・大きさ)を名前を付けて保存できます。
  (見本のダミープリセットはありません。自分で保存したものだけが並びます)
- カードを選ぶと、CPS/FPS/キーストローク/Pingが「いつもの位置」のまま、そのプリセットの見た目でプレビュー表示されます (位置は動きません)。
- 「適用」しないまま NavyHUD の画面が最前面でなくなる(ゲームに切り替えるなど)と、プレビューは自動で解除されます。
  「プレビュー解除」ボタンでも解除できます。
  数字はダミーではなく、実際の測定値・クリック数・キー入力がそのまま出ます (FPSが測れていないときは --)。
- 「適用」で本物のHUDに反映 (位置とON/OFFは変わりません)。名前変更・上書き・削除は保存したプリセットだけ。
- 文字タブ: 文字の大きさ / 1文字ごとの幅の比・高さの比 / 文字の上下位置 / 字間 を変えられます。全部プリセットに保存されます。

システム
- 左の「システム」は項目の一覧です。項目を押すと詳細が開きます: 起動 / 言語設定 / アプリの色 / FPS測定エンジン / データ
- 言語設定: 日本語 / English を切り替えられます (設定画面の表示言語。HUDの表示は変わりません)。
- アプリの色: 設定画面全体の色合いを変えられます (HUDの見た目には影響しません)。

初期設定
- 初回起動はすべてのHUDがOFFです。ONにしても「基本の見た目」(黒の半透明背景+白文字、枠なし)だけです。
- 「システム > すべて初期化」を押すと、この初回起動の状態にそのまま戻ります。
- 以前のバージョンの設定(%APPDATA%\NavyHUD\config.json)が残っていると、そちらが優先されます。
  初期設定を確認したいときは「すべて初期化」を一度押してください。

FPSが測れないとき (v2.6で強化)
- 「FPS詳細 > 測定 > 状態」に「PresentMonが終了しました (終了コード N) 理由」と出ます。その文面が原因です。
- NavyHUD は二重に起動しないようになりました。起動時に、前から動いている古い NavyHUD.exe を自動で終了します
  (二重に動くとFPS測定が取り合いになり、PresentMonが落ち続けます)。
  run.bat と NavyHUD.exe を同時に使わないでください。タスクトレイに残っている古い方は、起動時に自動で消えます。
- それでも落ちる場合、PresentMon の最新版が合っていない可能性があります。
  PresentMon-2.3.1-x64.exe (https://github.com/GameTechDev/PresentMon/releases/tag/v2.3.1) を取得して
  NavyHUD_PresentMon.exe の名前で NavyHUD.exe / navyhud.py と同じフォルダに置き、NavyHUD を起動し直してください。
- システム画面の「診断ログを開く」(%APPDATA%\NavyHUD\fps_debug.log) に原因が記録されます。
- FPS詳細の「状態」にも理由が表示されます。管理者権限が必要です(python直接起動時は自動で昇格を求めます)。
- PresentMon が同梱されていない場合は、起動時に自動でダウンロードします。

注意
- ゲームは「ボーダーレス/ウィンドウ」表示にしてください (排他フルスクリーンだとHUDが見えません)。
- キー入力を監視するため、ウイルス対策ソフトが警告することがあります (誤検知)。
